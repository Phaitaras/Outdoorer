# Outdoorer User Manual

## 1. What Outdoorer Does

Outdoorer helps you decide:
- what outdoor activity to do
- when to do it
- where to do it

It uses weather forecast data, activity-specific safety rules, and your weather preferences to produce recommendations.

## 2. First-Time Setup

1. Open the app.
2. Sign in with email or Google.
3. If using email registration, verify your email from the verification link.
4. Complete onboarding:
- select your preferred activities
- allow location access when prompted

After onboarding, you are routed to the Home tab.

## 3. Main Navigation

Outdoorer uses four main tabs:
- Home: quick recommendation overview for your preferred activities
- Plan: full planning tool for activity, date, location, and preferences
- Map: spatial view of plans, history, and friends
- User: profile, activity history, friends, settings

## 4. Home Tab Workflow

Use Home when you want a fast answer for today.

1. Check the location header.
2. Read current weather and near-future weather summary.
3. Browse activity cards:
- current sentiment
- short next-hours preview
- recommended time window
4. Tap an activity to open full detail.

Optional:
- open filters
- adjust weather preferences
- change location

## 5. Activity Detail Screen

This is the most detailed recommendation screen.

You can:
- inspect the 24-hour suitability graph
- select a specific hour
- read the hourly weather breakdown
- open the explanation modal for chart semantics
- save a plan via the plan-time modal

The recommended window is highlighted from the scoring output.

## 6. Plan Tab Workflow

Use Plan when you want to plan a future activity or a different location.

1. Choose activity type.
2. Choose date.
3. Choose location:
- search location
- or set location on map picker
4. (Optional) Enable weather preferences:
- rain tolerance
- temperature min and max
- wind tolerance
5. Open detail and save the plan.

## 7. Map Tab Workflow

The map shows activity markers with category-based views.

1. Switch marker category (plans, past activities, friends).
2. Use search to move map to a place.
3. Tap markers to open detail modal.
4. From modal actions, navigate to activity details or review flows.

Markers can cluster when many points are close together.

## 8. User Tab Workflow

In User, you can:
- view profile summary
- open upcoming and previous activity lists
- open friends area and manage requests
- edit profile settings
- toggle unit preference
- log out

Privacy settings control whether your activity history is visible to friends.

## 9. Friends and Reviews

Friends:
1. Search users.
2. Send or accept friend requests.
3. Open friend profile pages.

Reviews:
1. Open an activity that supports review flow.
2. Add star rating and text.
3. Edit or delete your review later if needed.

## 10. Understanding Recommendations

Outdoorer recommendations are produced in stages:

1. Safety override check:
- hazardous conditions force a poor outcome
2. Base scoring:
- weighted weather penalties produce a score
3. Preference penalties:
- optional deductions based on your tolerance settings
4. Sentiment mapping:
- score mapped to five levels (Poor to Great)
5. Window recommendation:
- best continuous time window selected for the day

## 11. Troubleshooting for Users

If location is wrong:
- ensure location permission is enabled
- manually set location from Home or Plan location controls

If weather data fails to load:
- check internet connection
- retry after a short delay

If login fails:
- verify credentials
- for email sign-up, verify your email first

If map search is unavailable:
- confirm internet connectivity
- try again after reopening the map tab

## 12. Limitations

- Forecast quality depends on external weather provider data.
- Best-fit recommendations are heuristic and may not match every user preference perfectly.
- Conditions can change quickly; always apply personal safety judgement before outdoor activity.
